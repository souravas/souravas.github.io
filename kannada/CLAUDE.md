# /kannada

- **Content**: [note.md](note.md) is the course and its only copy, so edit it here. `70 - Learn/Language/Kannada Gottilla.md` in the `hope` Obsidian vault holds only frontmatter and a link to this page, so never copy it over note.md.
- **Writing conventions**: 89 lessons, with checkpoints at 33, 69 and 89. Beginner lessons (1–32) are trimmed to a day's lines. Look-up tables, extra examples and written forms go under a `> [!later]- For later` fold rather than being deleted. Each lesson ends on a `> [!say] Say it today` callout, a one-row English and Kannada table.
- **Rendering**: the `kannada-note` plugin in vite.config.js runs [render.js](render.js) (build-time only) into `index.html` at its `<!--note-->`, `<!--lessons-->` and `<!--cards-->` markers. Dev reloads when the note is saved, and the plugin warns about any `#` link that lands on no id, such as a renamed heading; in a build that is an error. render.js reads only the Markdown the note uses: headings, pipe tables, lists, callouts (folded ones become `<details>`), code, bold, italics, links and wiki-links (`[[#Heading|alias]]`; a link to another vault note opens through `obsidian://open?vault=hope`). Ids: a `#` heading opens a `section.part`, `## Lesson N — Title` a `section.lesson` with id `lesson-N`, and a heading inside a lesson gets a `lesson-N-…` id.
- **Kannada text** is set in JetBrains Mono, because Inter Tight draws `I` and `l` alike and the notation's capitals mark sounds (`iddIra`). Which table columns are English is set by `ENGLISH_COLUMNS` in render.js. In a Kannada column, a cell that is English instead is written all in italics (`*bare stem*`), or with its Kannada in backticks; otherwise it is set as Kannada, hidden by Cover and read out by the voice as Kannada.
- **Cards**: render.js builds them from the lessons' own tables, one card per row and Kannada column. It leaves out exercise tables (the ones an Answers callout follows), cells with backticks, `SKIP_COLUMNS` and lines over 140 characters. Tables in `[!later]` folds become drill-only cards. Checkpoints have no quiz; their exercises get a "Run as cards" button built from the answers (`checkCards`). A card's id is a hash of its English and Kannada. The cards go to `/kannada/cards.<hash>.json`, named in the page's `<meta name="cards">`, and to `/kannada/anki.txt` (`ankiDeck`). The Anki deck uses each card's id as its GUID, so importing it again updates the cards instead of duplicating them.
- **Speech**: with a `kn` voice on the device, [speech.js](speech.js) marks the root `can-speak` and Kannada becomes tappable. [script.js](script.js) converts the note's spelling into Kannada script for the voice. **Every English word or name used in a Kannada line must be listed in its `ENGLISH` or `NAMES` list**, or the voice reads it as Kannada. `SAID_AS` holds the names the note respells.
- **Modules**: `main.js` (bar, Lessons sheet, Cover, lesson on screen), `today.js` (the Today view: the day's checklist and only the current lesson), `deck.js` (the quiz `<dialog>`), `cards.js` (loads the cards file), `store.js` (localStorage key `kannada`: Leitner boxes `INTERVALS`, `NEW_PER_DAY`, lesson progress; the page works without it), `backup.js` (Start here's line that saves the progress as a file and restores one).
- **Progress** lives in the browser alone, so `store.js` can write all of it out (`snapshot`) and read a copy back (`readSnapshot`, which keeps only fields it knows, each checked). A new field in the progress has to be added to `clean()` there, or a restore drops it. `LAST_LESSON` in store.js is the note's last lesson number, and a card id is ten hex characters; `npm test` checks both against the note.
- **The bar** on a phone has room for two links beside its buttons: Today and Whole note. Start here is in the footer (today.js puts it there), and while the day's plan shows, with its own Review button, the bar's Review is hidden below 760px. Check a phone width with reviews due before adding anything to the bar.
- **Offline**: main.js registers the shared [/sw.js](../public/sw.js) with scope `/kannada`. It keeps the page, its script and the cards file, so a lesson and its quiz open without a network.
- **Tests**: `script.test.js`, `render.test.js` and `store.test.js`, run by `npm test`.
- **First paint**: an inline script in the head adds `is-today` to the root before paint, and the note stays invisible until today.js adds `is-ready` (CSS shows it after 3s if the script fails).
- **`content-visibility: auto`** is set on each lesson. Measuring anything inside a skipped lesson forces it to lay out, so main.js finds the lesson on screen by measuring the `section.lesson` elements, never their headings.
