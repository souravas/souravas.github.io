# /start/v1

/start's first design, its default until November 2026 (see [../CLAUDE.md](../CLAUDE.md)): the groups as plain lists of links, in columns on wider screens. [index.html](index.html) is only a head and a `<!--bookmarks-->` marker, which the `start-bookmarks` plugin fills with [../bookmarks.html](../bookmarks.html), so **bookmarks are changed there, never here**. [main.js](main.js) imports /start's prompt (`../prompt.js`) and registers `/sw.js` with this page's scope. Only [style.css](style.css) is this page's own.

- **Layout**: below 760px the groups stack in one column, each with its links in two columns. From 760px they run in three newspaper-style columns of twelve links each, in a page at most 960px wide: Daily and Learn, then Code and Design, then Prep, Finance and Fun. Each column after the first starts at a group with `class="column-start"` in bookmarks.html, which forces a column break. Without it, the browser's balancing decides where each group lands, and moving a group or adding links can push one into a neighbouring column. Prep holds the interview and engineering courses, and Learn the general ones. The third column, with three headings to the others' two, is the longest and sets the page's height.
- **Height**: from 760px, rows and gaps shrink with the window's height (28px and 16px at the least), so the page fits without scrolling in a window about 550px tall. The formulas in `style.css` are tuned to the page's height (about 785px at full size), so check the fit again after adding links.
