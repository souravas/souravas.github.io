# /start/v2 — Keypad

A trial design of /start (see [../CLAUDE.md](../CLAUDE.md), *Trial designs*): every bookmark a key, each group a keypad two keys wide. [index.html](index.html) is only a head and a `<!--bookmarks-->` marker, which the `start-bookmarks` plugin fills with /start's icon sprite and `<main>`, so **bookmarks are changed in `start/index.html`, never here**. [main.js](main.js) imports /start's prompt (`../prompt.js`) and registers `/sw.js` with scope `/start/v2`, which serves the page from cache at once, as it does /start. Only [style.css](style.css) is this page's own.

- **Legends**: a key prints its short code (`data-alias`) top left and, when it opens several tabs, their count top right, from `data-tabs`, which the plugin adds (the URLs in `data-also` plus the href). Both are CSS `content` with empty alt text, so screen readers read only the name.
- **Layout**: one grid. Phones put the keypads two to a row and the pinned links in one row of icons, their names hidden as on /start. From 760px the keypads go four to a row, and from 1280px all seven go in one row, where the pinned row shares the page's columns (`column-gap: inherit`), so each pinned key sits over a keypad. At 1280px a key is 77px wide, just room for "AlgoMonster" on one line in the 12px names use below 1440px; a wider gap, more padding or a longer one-word name there would break a word in two. A name on two lines runs into the key's lower padding, which is sized for it at the smallest key (80px).
- **Height**: from 760px, `--key` and `--gap` grow with the window's height (80→96px and 16→28px over 560–800px of it), so the seven-keypad page fits a window about 560px tall. The tallest keypad sets the page's height: today Fun, whose seven links take four rows. A group of nine or more would add a fifth row, and the formulas would need tuning again.
