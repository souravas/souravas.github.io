# /start/v3 — Shelves

A trial design of /start (see [../CLAUDE.md](../CLAUDE.md)): a shelf per group, its name on the left and its links as wide buttons on one row. [index.html](index.html) is only a head and a `<!--bookmarks-->` marker, which the `start-bookmarks` plugin fills with [../bookmarks.html](../bookmarks.html), so **bookmarks are changed there, never here**. [main.js](main.js) imports /start's prompt (`../prompt.js`) and registers `/sw.js` with this page's scope (`/start/v3`), which serves the page from cache at once. Only [style.css](style.css) is this page's own.

- **Legends**: a button ends with its short code (`data-alias`) or, when it opens several tabs, their count, from `data-tabs`, which the plugin adds. Both are a CSS `::after` with empty alt text, so screen readers read only the name; a link with both shows the count.
- **Layout**: phones stack each group's name over its links, two to a row, with the pinned links as one row of icons whose names are hidden as on /start. From 760px the links go four to a row. From 1280px the names move into a 96px column (`--label`) and every shelf uses the same seven columns, as do the prompt and the pinned row, which then shows its names. A button is narrowest at 1280px (149px), just room for "Downloads" beside its `×8` in the 14px used below 1440px: a longer word, a longer short code or a narrower button breaks a word in two, so check the narrowest width after any of those. Below 360px the short codes go, for the same reason. Seven is the largest group (Fun): an eighth link would wrap that shelf onto a second row, so raise the column count (and check the narrowest width) first.
- **Height**: from 1280px, the rows, the gaps between shelves and the space around the pinned row grow with the window's height (44→56px, 6→10px and 12→24px over 560–800px of it), so the page fits a window about 560px tall.
