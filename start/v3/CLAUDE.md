# /start/v3 — Shelves

A trial design of /start (see [../CLAUDE.md](../CLAUDE.md)): a shelf per group, its name on the left and its links as wide buttons on one row. [index.html](index.html) is only a head and a `<!--bookmarks-->` marker, which the `start-bookmarks` plugin fills with [../bookmarks.html](../bookmarks.html), so **bookmarks are changed there, never here**. [main.js](main.js) imports /start's prompt (`../prompt.js`) and registers `/sw.js` with this page's scope (`/start/v3`), which serves the page from cache at once. Only [style.css](style.css) is this page's own.

- **Legends**: a button ends with its short code (`data-alias`) or, when it opens several tabs, their count, from `data-tabs`, which the plugin adds. Both are a CSS `::after` with empty alt text, so screen readers read only the name; a link with both shows the count.
- **Layout**: phones stack each group's name over its links, two to a row. From 760px the links go four to a row. From 1280px the names move into a 96px column (`--label`) and every shelf uses the same six columns, as does the prompt. A button is narrowest just past each step: about 150px at 360px, 165px at 760px and 175px at 1280px. So those bands (below 420px, 760–840px and 1280–1440px) set the names in 14px with less space around them, which keeps a one-word name whole beside its short code ("AlgoMonster" and `amo`); two-word names may take two lines there. Check those widths after a longer name or short code. Below 360px the short codes go, so every word stays whole (that rule has to come after the ones that draw the codes, or it loses). Six is the largest group (Daily, Code, Design, Learn): a seventh link would wrap that shelf onto a second row, so raise the column count (and check the narrowest width) first.
- **Height**: from 1280px, the rows, the gaps between shelves and the space under the prompt grow with the window's height (44→56px, 6→10px and 12→24px over 560–800px of it), so the page fits a window about 500px tall (450px before Finance added a seventh shelf).
