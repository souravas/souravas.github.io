# /cloud

The first of the three opener pages, and where their shared behaviour is written down: [/invest](../invest/CLAUDE.md) and [/downloads](../downloads/CLAUDE.md) are the same page for other sites, and their notes hold only what differs.

- Typing `souravas.com/cloud` opens the cloud drives (Google Drive and Photos, Koofr, Drime, Proton Drive): [../shared/opener.js](../shared/opener.js), which its [main.js](main.js) imports, opens all but the first in new tabs, in order, then sends this tab to the first with `location.replace`, so Back from it skips /cloud. /start has no key for this page, but its prompt finds it, by name or by a site it opens ("drive"), through a hidden entry in its page.
- **The sites are the `ol.sites` in [index.html](index.html)**, each a link with `target="_blank"` named by its host; add, remove or reorder them there. The build copies their hosts to /start's prompt (`opener-sites` in vite.config.js), so nothing else needs changing. The page opens only those addresses, fixed in the page, never one from its URL, so no souravas.com link can send a visitor elsewhere.
- **Pop-ups**: browsers block tabs a page opens on its own until the site is allowed pop-ups, so allow them for souravas.com once (Chrome, Brave: the blocked pop-up icon at the end of the address bar, then *Always allow*). Until then nothing leaves this tab: the page stays up, says the tabs were blocked, and its *Open the rest* button opens one more per click, since a click lets one pop-up through. Each site that opened is marked; this tab moves to the first once the others are all open. Both paths were checked in headless Brave, with the popup blocker on and off.
- A page Chrome prerenders while the address is still being typed waits for `prerenderingchange`, so the tabs open only once the page is really opened.
- Laid out as /fit is, with the "‹ Start" link in a 120px gutter on wider screens. The list is all that shows when the tabs open, and only for a moment.
- No service worker: offline there is nothing to open. It loads the analytics beacon like every built page.
- **Shared**: the script and styles are [../shared/opener.js](../shared/opener.js) and [../shared/opener.css](../shared/opener.css), which each opener page's `main.js` and `style.css` only import (/downloads fills its list first and adds its editor), so a change there shows on all of them.
- **Another such page** needs only its own `index.html` with its `ol.sites`, those two one-line files, its name in vite.config.js's `PAGES`, and its `CLAUDE.md` and row in the root's Pages table (steps 2 to 4 of the root's *Adding a page*, and step 5 if it gets a key on /start). A key on /start, or an entry in its hidden list as /cloud has, lets the prompt find the page by its sites with no more work.
