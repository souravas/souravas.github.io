# Repository instructions

Read the repository-root [CLAUDE.md](CLAUDE.md) at the start of each task. It covers the site structure, development commands, and conventions shared across pages.

Before working on a page, read the `CLAUDE.md` in its source directory if one exists. The Pages table in the root guide links to these notes. This also applies when a change affects a page through shared code or `vite.config.js`.

Keep repository and page guidance in the corresponding `CLAUDE.md` files so Codex and Claude Code use the same notes.
