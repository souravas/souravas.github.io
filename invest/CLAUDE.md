# /invest

- Typing `souravas.com/invest` opens Kite, Coin, Kite beta, the IPO trackers (Chittorgarh, then ipowatch's grey-market premiums) and the Cashflow sheet, as [/cloud](../cloud/CLAUDE.md) does for the cloud drives: all but the first in new tabs, in order, then this tab moves to the first (Kite) with `location.replace`. /start's Invest key (last in Misc, alias `in`) opens this page. The IPO trackers had a page of their own, /ipo, until November 2026, and Cashflow a key of its own on /start; both now open only from here.
- **The page is /cloud's, with other sites.** Its [main.js](main.js) and [style.css](style.css) only import [../shared/opener.js](../shared/opener.js) and [../shared/opener.css](../shared/opener.css), which the opener pages share; /cloud's notes cover how it behaves (blocked pop-ups, prerendering, layout) and hold for this page too.
- **The sites are the `ol.sites` in [index.html](index.html)**, each a link with `target="_blank"` named by its host; change them there. The build copies their hosts onto /start's Invest key (`opener-sites` in vite.config.js), so its prompt finds the page by them ("kite", "ipo", "docs").
- No service worker; it loads the analytics beacon like every built page.
